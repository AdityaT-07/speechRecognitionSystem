# 🎤 Speech Recognition System (Python – Tkinter)

A desktop-based **Speech Recognition System** developed using **Python and Tkinter**, capable of converting **speech to text**, **text to speech**, and performing **real-time speech recognition** with a user-friendly graphical interface.

This project is designed as an academic and practical application of speech processing concepts using Python.

---

## 📌 Features

### 🔊 Text to Speech
- Converts user-entered text into spoken audio
- Uses `pyttsx3` for offline text-to-speech
- Simple and fast playback

### 🎧 Speech to Text (Audio File)
- Upload audio files (`.wav`, `.mp3`)
- Converts speech into readable text
- Save output as a `.txt` file
- Uses Google Speech Recognition API

### 🎙 Real-Time Speech Recognition
- Live speech recognition using microphone
- Supports multiple languages:
  - English
  - Hindi
  - Marathi
- Start and Stop controls

### 🎨 GUI Interface
- Built using `Tkinter` and `ttk`
- Modern UI themes using `ttkthemes`
- Smooth page navigation with loading animations
